# LittleFarm

**LittleFarm** คือเกมจำลองการทำฟาร์มที่พัฒนาด้วยภาษา Java เป็นส่วนหนึ่งของโครงงาน Final Project ในรายวิชา Object-Oriented Programming (OOP)

ภายในเกมผู้เล่นจะได้รับบทบาทเป็นเจ้าของฟาร์ม สามารถปลูกพืช เลี้ยงสัตว์ เก็บเกี่ยวผลผลิต ซื้อขายสินค้า และมีปฏิสัมพันธ์กับตัวละครภายในเกม โดยผู้เล่นจะต้องบริหารจัดการทรัพยากรและปรับเปลี่ยนวิธีการทำฟาร์มให้เหมาะสมกับฤดูกาลและสภาพอากาศ

## ความสามารถของเกม (Features)

### 1. ระบบการปลูกพืช (Farming System)
- สามารถซื้อเมล็ดพันธุ์และนำมาปลูกภายในฟาร์มได้
- สามารถรดน้ำและเก็บเกี่ยวผลผลิตได้
- พืชแต่ละชนิดมีระยะเวลาในการเจริญเติบโตแตกต่างกัน
- พืชแต่ละชนิดสามารถปลูกได้เฉพาะในฤดูกาลที่เหมาะสม

### 2. ระบบสัตว์เลี้ยง (Animal System)
- สามารถเลี้ยงสัตว์ภายในฟาร์ม เช่น ไก่และวัว
- สามารถให้อาหารสัตว์ได้
- สามารถเก็บผลผลิตจากสัตว์เลี้ยงได้
- นำผลผลิตจากสัตว์ไปขายเพื่อสร้างรายได้

### 3. ระบบฤดูกาลและสภาพอากาศ (Seasons & Weather System)
- มีการเปลี่ยนแปลงฤดูกาลภายในเกม
- สภาพอากาศมีผลต่อการทำฟาร์ม
- มีสภาพอากาศที่แตกต่างกัน เช่น ฝนตกและหิมะตก
- ระบบสภาพอากาศมีผลต่อการเจริญเติบโตของพืช

### 4. ระบบบริหารจัดการฟาร์ม (Farm Management)
- จัดการทรัพยากรและสิ่งของภายในเกม
- ซื้อเมล็ดพันธุ์และอุปกรณ์สำหรับทำฟาร์ม
- ขายผลผลิตจากพืชและสัตว์
- พูดคุยและทำกิจกรรมร่วมกับตัวละครภายในเกม

### 5. ระบบบันทึกและโหลดข้อมูล (Save & Load System)
- สามารถบันทึกความคืบหน้าของเกมได้
- สามารถโหลดข้อมูลที่บันทึกไว้กลับมาเล่นต่อได้
- จัดเก็บข้อมูลเกมในรูปแบบไฟล์ข้อความ

### 6. ระบบจัดการข้อผิดพลาด (Exception Handling)
- ตรวจสอบการกระทำที่ไม่ถูกต้องภายในเกม
- ป้องกันการทำกิจกรรมที่ไม่เป็นไปตามเงื่อนไขของเกม
- แสดงข้อความแจ้งเตือนเมื่อเกิดข้อผิดพลาด

## วิธีติดตั้งและเรียกใช้งาน (How to Run)

1. Clone โปรเจกต์จาก GitHub

   ```bash
   git clone https://github.com/6810610060/LittleFarm.git
   ```

2. เปิดโปรเจกต์ด้วยโปรแกรมที่รองรับภาษา Java เช่น Visual Studio Code

3. ตรวจสอบว่าติดตั้ง Java Development Kit (JDK) เรียบร้อยแล้ว

4. เปิดโฟลเดอร์ Source Code และค้นหา Main Class ที่มีเมธอด `main()`

5. เรียกใช้งาน Main Class เพื่อเริ่มต้นเกม

## วัตถุประสงค์ของโปรเจกต์ (Project Objectives)

- เพื่อประยุกต์ใช้ความรู้เกี่ยวกับการเขียนโปรแกรมเชิงวัตถุในการพัฒนาเกม
- เพื่อเรียนรู้การออกแบบและการทำงานร่วมกันของ Class ต่าง ๆ
- เพื่อฝึกการพัฒนาระบบและกลไกต่าง ๆ ภายในเกม
- เพื่อพัฒนาทักษะการแก้ไขปัญหาและการตรวจสอบข้อผิดพลาดของโปรแกรม
- เพื่อฝึกการทำงานร่วมกันเป็นทีมผ่าน Git และ GitHub
